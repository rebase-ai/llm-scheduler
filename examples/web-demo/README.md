# LLM Scheduler Web Demo

This is a web demo for the LLM Scheduler. It is built with Next.js and uses the Assistant UI React library for the chat interface.

## TL;DR

```bash
# choose a demo server. eg. the simple chatbot server
export OPENAI_API_KEY="..."
python examples/chat_bot.py

# install dependencies
pnpm i
pnpm dev
```
